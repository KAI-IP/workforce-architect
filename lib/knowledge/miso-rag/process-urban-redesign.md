# 프로세스 맵: 도시 재설계 (노후 구역 정비: 철거·인프라·재설치) (urban-redesign)

> **PoC 가정**: 아래 흐름은 PoC 검증용 프로세스 맵입니다.

도시정비/재개발 실행 흐름을 기준으로 한 PoC 프로세스 맵. 물리·현장 직무(FIELD) 비중이 높아 3레인 분해 검증에 유용.

**레인 요약(laneSummary):** AI=2 · EDGE=2 · FIELD=3

## 단계 1. 조사·계획

**흐름:** 데이터 분석 AI(AI) → 프로젝트 총괄(PM)(EDGE) → 법무·인허가 검토자(EDGE)

- **데이터 분석 AI** (AI · NCS: data-analysis): GIS·인구·인프라 데이터 분석, 정비 우선순위 시뮬레이션 → 핸드오프: 프로젝트 총괄
- **프로젝트 총괄(PM)** (EDGE · NCS: project-management) [게이트]: 정비 범위·일정·예산 수립, 이해관계자·인허가 조율 → 핸드오프: 법무 검토자
- **법무·인허가 검토자** (EDGE · NCS: legal-affairs): 도시계획·환경 법령 검토, 보상·계약 리스크 점검 → 핸드오프: 철거 작업자

## 단계 2. 철거·해체

**흐름:** 건축물 해체 작업자(FIELD)

- **건축물 해체 작업자** (FIELD · NCS: demolition): 해체계획 기반 구조물 철거, 비산먼지·폐기물 관리 → 핸드오프: 하수도 정비 작업자

## 단계 3. 인프라 정비

**흐름:** 하수도 정비 작업자(FIELD) → 데이터 분석 AI(AI)

- **하수도 정비 작업자** (FIELD · NCS: sewerage): 하수관로 조사·굴착·보수, 통수 시험 → 핸드오프: 설비 설치 작업자
- **데이터 분석 AI** (AI · NCS: data-analysis): 관로 센서·정비이력 모니터링, 결함 우선순위 산출 → 핸드오프: 하수도 정비 작업자

## 단계 4. 재설치·시운전

**흐름:** 기계설비 설치 작업자(FIELD)

- **기계설비 설치 작업자** (FIELD · NCS: equipment-installation): 신규 설비 반입·설치·배관/배선 연결·시운전 → 핸드오프: 프로젝트 총괄

## 단계 5. 인수·운영이관

**흐름:** 프로젝트 총괄(PM)(EDGE)

- **프로젝트 총괄(PM)** (EDGE · NCS: project-management) [게이트]: 준공 검수, 인수인계 문서 확인, 운영 이관 → (종료)

## 핸드오프 리스크 (handoffRisks)

- 철거 전 법무·인허가 게이트(석면조사·해체심의) 미통과 시 위법. EDGE 승인 필수.
- FIELD 작업 간 순서 의존(철거→하수도→설치)이 강해 일정 핸드오프 지연이 전체 공정 리스크.
